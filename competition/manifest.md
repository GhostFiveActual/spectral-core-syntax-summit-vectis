# Syntax Summit — VECTIS Competition Manifest

Project: VECTIS
Team: Spectral Core
Competition: Syntax Summit
Platform: Devpost
Deadline: January 14, 2027 @ 7:00 AM EST

## Mission

Create a domain-specific language for readable, deterministic automation and
workflow orchestration.

## Judging Priorities

- Innovation & Originality — 25
- Technical Implementation — 25
- Language Design — 20
- Real-World Impact — 15
- Documentation & Presentation — 10
- User Experience — 5

## Required Outcomes

VECTIS must include:

- a formal language specification
- lexer
- parser
- abstract syntax tree
- deterministic diagnostics
- semantic analyzer
- intermediate execution representation
- runtime
- controlled capability adapters
- command-line interface
- real working examples
- automated conformance tests
- accessible demonstration interface
- architecture documentation
- user documentation
- hackathon demonstration materials

## Protected Principles

1. VECTIS is a real DSL, not a prompt wrapper.
2. The grammar and compiler define language meaning.
3. AI may help author VECTIS but does not interpret valid source.
4. Semantics must be deterministic.
5. Diagnostics must include meaningful source information.
6. Runtime capabilities must be explicit.
7. Generated code remains untrusted until tested.
8. Tests must not be weakened simply to obtain green status.
9. Accessibility is part of the product architecture.
10. Documentation must match implementation.
11. Autonomous development must remain inside this repository.
12. External publication and competition submission require human action.
