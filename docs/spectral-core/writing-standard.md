# Ghost Five Writing Standard

## Voice

Write the way Ghost Five operates: calm, direct, disciplined, technical, and outcome focused.

State what something does. State why it matters. State the boundary. Stop when the point is complete.

## Required style

1. Use direct sentences and concrete nouns.
2. Prefer active voice when the actor matters.
3. Explain technical decisions in operational terms.
4. Separate facts, current behavior, planned work, and assumptions.
5. Use tables when comparison is clearer than a long list.
6. Use numbered lists when order or accountability matters.
7. Keep headings specific.
8. Use Ghost Five, Spectral Core, and VECTIS consistently.

## Prohibited style

Do not use em dashes in prose. Use a period, comma, colon, or parentheses.

Do not stack dash bullets as the default way to explain a topic. Use paragraphs, numbered lists, tables, or star bullets.

Do not use generic trend introductions, artificial superlatives, vague integration claims, or inflated marketing language when a direct statement is available.

Do not write claims that the implementation cannot prove.

Do not add artificial enthusiasm, fake certainty, or generic summary language.

## Technical exceptions

Hyphens are acceptable when required by a command, filename, identifier, standard technical term, version string, or source code. The rule is about prose style, not breaking technical syntax.
