# VECTIS Demo

The canonical demo exercises the VECTIS language, compiler, deterministic execution graph, runtime, branch selection, and diagnostics path without requiring external capabilities.

Run it with:

```bash
python examples/demo/run_demo.py
```

Or use the CLI directly:

```bash
vectis check examples/demo/demo.vectis
vectis inspect examples/demo/demo.vectis
vectis run examples/demo/demo.vectis
```

For an interactive demonstration, launch VECTIS Studio:

```bash
vectis studio
```
