# VECTIS

VECTIS is a deterministic domain-specific language for expressing automation
and workflow orchestration in syntax designed to remain readable to humans.

Built by Spectral Core for Syntax Summit.

## Core Compiler Pipeline

Source
  -> Lexer
  -> Parser
  -> AST
  -> Semantic Analyzer
  -> Execution Graph
  -> Runtime
  -> Capability Adapters

## Core Boundary

AI may assist a user in writing VECTIS.

AI does not define the meaning of VECTIS.

The compiler and runtime do.
